# Changelog

## v1.2.0 — 2026-11-17

- Назва проєкту: Unthread.
- Нова головна: заголовок «Що кажуть про бренд у Threads?», рядок пошуку в стилі Google з кнопкою всередині, підказки для пошуку.
- Білий фон, менші заокруглення, футер з колонками «Документи» та «Контакти».
- Сторінка `/terms` — Умови використання.

## v1.1.0 — 2026-11-17

- Футер на всіх сторінках: опис сервісу, посилання на політики, контактний email, дисклеймер щодо Meta.
- Сторінка `/privacy` — Політика конфіденційності під BrandPulse (Закон України «Про захист персональних даних» + GDPR), з розділом про видалення даних `/privacy#deletion` для App Review у Meta.
- Сторінка `/cookies` — Політика файлів cookie (сайт не встановлює cookie, банер згоди не потрібен).
- Дані власника налаштовуються в `lib/site.ts` або через `NEXT_PUBLIC_*` змінні.

## v1.0.0 — 2026-11-17

Перший реліз.

- Сторінка з пошуком бренду і трьома колонками: негативні / позитивні / нейтральні згадки.
- Бекенд `GET /api/analyze?q=<бренд>`: пошук публічних постів через Threads API `keyword_search` з пагінацією і дедуплікацією.
- Класифікація тональності щодо конкретного бренду через Claude (пакети по 25 постів, паралельно), з відсіюванням нерелевантних збігів.
- Резервний словниковий класифікатор (UA/EN/RU), якщо немає ключа Claude або API недоступний.
- Демо-режим без токена Threads.
- Кеш результатів (TTL), обмеження частоти запитів на IP, `GET /api/health`.
- Темна тема, адаптивна верстка, Dockerfile, інструкція з деплою на Vercel.
